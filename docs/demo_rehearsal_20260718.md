## Security Remediation During Rehearsal

The rehearsal found that the frontend contained and displayed source URL data.
The following targeted fix was made before any final screenshot:

- Removed the embedded RTSP default from the frontend input.
- Stopped all automatic source URL backfill into the input.
- Changed source diagnostics to a generic controlled-source status.
- Removed raw `source_url` from public `/status` stream aliases and masked
  `/stream/start` response URLs.
- Added UI-side redaction for status payloads from a pre-restart legacy server.

The already-running `8000` process was not restarted. Its frontend uses the
new static redaction behavior, while the backend schema hardening becomes
effective for that instance at its next approved restart. Do not display raw
`/status` JSON or process command lines during the formal demonstration.
