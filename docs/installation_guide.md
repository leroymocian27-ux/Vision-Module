# Installation Guide

Version: `fall-monitor-stable-v1.0-rc`

## Prerequisites

- Windows with PowerShell
- Python environment compatible with the project dependencies
- Model files listed in `models/model_manifest.json` or generated by `scripts/validate_config.py`

## Install Dependencies

```powershell
pip install -r requirements.txt
```

For an exact handoff environment, prefer `requirements.lock` when it is present in a release bundle.

## Validate Configuration

```powershell
python scripts/validate_config.py --profile safe_demo
```

## Start Safe Demo

```powershell
.\scripts\start_safe_demo.ps1
```

Default demo URL:

```text
http://127.0.0.1:8000/demo
```

## Run Smoke

```powershell
python scripts/run_stable_smoke.py --profile safe_demo
```
