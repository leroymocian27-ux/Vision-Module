# New Pose Action Script

日期: `2026-06-21`

仓库: `D:\Program\vision_service`

## 目的

本脚本给现场采集人员直接照着执行，减少动作命名漂移和 session 结构混乱。

## 通用规则

- 全程保持 `pose_enabled=false`
- 不重启到真实 Pose 模式
- 每次只允许单人入镜
- 尽量保持全身入镜
- 不贴左/右边界，除非动作就是 `near_edge`
- 跌倒相关动作必须使用软垫，只做可控模拟

## Session 01：空场与站立

### 1. no_person

- 开始口令: “开始空场”
- 结束口令: “结束空场”
- 时长: `20` 秒
- 人物位置: 无人
- 失败重录条件: 画面中误入人员

### 2. standing_front

- 开始口令: “开始正面站立”
- 结束口令: “结束正面站立”
- 时长: `30` 秒
- 人物位置: 画面中央
- 失败重录条件: 全身未入镜或频繁移动

### 3. standing_side

- 开始口令: “开始侧身站立”
- 结束口令: “结束侧身站立”
- 时长: `30` 秒
- 人物位置: 画面中央
- 失败重录条件: 身体旋转过多，无法保持侧身

### 4. standing_back

- 开始口令: “开始背身站立”
- 结束口令: “结束背身站立”
- 时长: `30` 秒
- 人物位置: 画面中央
- 失败重录条件: 人物持续回头或侧转

### 5. walking_slow

- 开始口令: “开始慢走”
- 结束口令: “结束慢走”
- 时长: `30` 秒
- 人物位置: 画面中央横向或轻微纵向移动
- 失败重录条件: 超出画面或速度过快

## Session 02：坐姿与弯腰

### 6. sitting_normal

- 开始口令: “开始正常坐姿”
- 结束口令: “结束正常坐姿”
- 时长: `30` 秒
- 人物位置: 画面中央
- 安全提示: 椅子稳定，避免滑动
- 失败重录条件: 人体被桌椅严重遮挡

### 7. sitting_side

- 开始口令: “开始侧坐”
- 结束口令: “结束侧坐”
- 时长: `30` 秒
- 人物位置: 画面中央
- 失败重录条件: 头部或下肢频繁出镜外

### 8. bending_pickup

- 开始口令: “开始弯腰拾物”
- 结束口令: “结束弯腰拾物”
- 时长: `30` 秒
- 人物位置: 画面中央
- 安全提示: 缓慢弯腰，不要急蹲
- 失败重录条件: 动作太快或手部完全挡住躯干

### 9. squat

- 开始口令: “开始深蹲”
- 结束口令: “结束深蹲”
- 时长: `30` 秒
- 人物位置: 画面中央
- 安全提示: 缓慢起落，必要时有人保护
- 失败重录条件: 动作不完整或频繁离开画面

### 10. recovery_standing

- 开始口令: “开始起身恢复”
- 结束口令: “结束起身恢复”
- 时长: `20` 秒
- 人物位置: 画面中央
- 失败重录条件: 起身动作被遮挡

## Session 03：倒地静态

### 11. lying_side

- 开始口令: “开始侧躺”
- 结束口令: “结束侧躺”
- 时长: `30` 秒
- 安全提示: 使用软垫
- 失败重录条件: 头、躯干、腿部缺失过多

### 12. lying_back

- 开始口令: “开始仰躺”
- 结束口令: “结束仰躺”
- 时长: `30` 秒
- 安全提示: 使用软垫
- 失败重录条件: 全身未入镜

### 13. lying_prone

- 开始口令: “开始俯卧”
- 结束口令: “结束俯卧”
- 时长: `30` 秒
- 安全提示: 保持呼吸顺畅
- 失败重录条件: 躯干被完全遮挡

### 14. fallen_hold

- 开始口令: “开始倒地保持”
- 结束口令: “结束倒地保持”
- 时长: `30` 秒
- 安全提示: 使用软垫，不翻身
- 失败重录条件: 起身过早或姿态频繁变化

## Session 04：模拟跌倒

### 15. fall_simulated_side

- 开始口令: “开始侧向模拟跌倒”
- 结束口令: “结束侧向模拟跌倒”
- 时长: 站立 `5` 秒 + 跌倒 + 保持 `20` 秒
- 安全提示:
  - 使用软垫
  - 不做危险真摔
  - 只做可控模拟
  - 保持全身入镜
  - 不让第二个人进入画面
  - 不遮挡头部和躯干
- 失败重录条件: 跌倒过程太快看不清，或跌倒后立即调整身体

### 16. fall_simulated_back

- 开始口令: “开始后仰模拟跌倒”
- 结束口令: “结束后仰模拟跌倒”
- 时长: 站立 `5` 秒 + 跌倒 + 保持 `20` 秒
- 安全提示: 同上
- 失败重录条件: 头部或躯干出画

### 17. recovery_standing

- 开始口令: “开始从倒地恢复站立”
- 结束口令: “结束恢复站立”
- 时长: `20` 秒
- 安全提示: 缓慢起身
- 失败重录条件: 身体被遮挡或动作中断

建议:

- 整个 Session 04 重复 `3` 次

## Session 05：困难样本

### 18. partial_occlusion

- 开始口令: “开始部分遮挡”
- 结束口令: “结束部分遮挡”
- 时长: `20` 秒
- 失败重录条件: 遮挡过度导致动作不可识别

### 19. near_edge

- 开始口令: “开始靠边”
- 结束口令: “结束靠边”
- 时长: `20` 秒
- 位置: 左边界和右边界各一轮
- 失败重录条件: 全身只剩一半

### 20. far_distance

- 开始口令: “开始远距离”
- 结束口令: “结束远距离”
- 时长: `20` 秒
- 失败重录条件: 人体过小不可辨

### 21. close_distance

- 开始口令: “开始近距离”
- 结束口令: “结束近距离”
- 时长: `20` 秒
- 失败重录条件: 身体贴镜头导致严重裁切

### 22. dark_clothes / bright_clothes / loose_clothes

- 每类时长: `20` 秒
- 人物位置: 画面中央
- 失败重录条件: 光照或画面质量异常

## 现场备注要求

每个 session 必须记录:

- 实际执行动作
- 是否完整入镜
- 是否存在遮挡
- 是否存在边界裁切
- 是否重录
- 安全异常

- `notes.md`
