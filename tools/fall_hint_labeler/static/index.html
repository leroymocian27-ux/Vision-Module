操作说明

拖拽图片可以新建框，点击框后可以改类别或删除。
`pass_train`：允许进入训练集。
`pass_val`：允许进入验证集。
`needs_fix`：这张图仍需继续修框或复核。
`reject`：这张图不进入后续数据集。

快捷键：
`Ctrl/Cmd + S` 只保存框
`Shift + T` 保存并标记 `pass_train`
`Shift + V` 保存并标记 `pass_val`
`Shift + F` 保存并标记 `needs_fix`
`Shift + R` 保存并标记 `reject`
