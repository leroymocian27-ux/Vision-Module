YOLO person labeler

Source

Operation

Drag on the image to create a person box.
Click a box to select it.
Delete removes the selected box.
Save writes a YOLO txt label.
For no-person frames, click No person, then Save.
Keyboard: left/right arrows, Delete, Ctrl+S.

Class Rule

Only class 0: person.
Label every visible human, including standing, walking, sitting, bending, kneeling, lying, falling, and fallen people.
Do not label action classes.
